# 新增「信息可视化」栏目 — 精神疾病时空数据图谱（Data Atlas）

## 目标

在 symgene 单页应用中新增第 7 个顶级栏目「信息可视化」(id: `atlas`)，包含：
- **主视图「时空矩阵」**：横轴=年份（时间滑块+播放动画），纵轴=地区/族裔切换；同一疾病同一色相、深浅=患病率；不同疾病按谱系色系分层叠加；单元格内嵌细柱高度=治疗可及性
- **副窗口「关联散点图」**：X/Y 轴可选（患病率 / 治疗可及性 / 人均GDP / 精神科医生每10万人 / 心理健康支出占比等代理指标），每点=国家或族裔组，Pearson r + 拟合线，与主矩阵悬停联动，随时间滑块联动年份
- **谱系图例区**：疾病按谱系簇分组（心境/焦虑恐惧/精神病性/神经发育/物质成瘾/进食），同一谱系同一色系，概念上呼应前沿综述中的 HiTOP 谱系分类
- **数据来源与免责声明区**：公益科普必需（数据为流行病学估计非诊断依据；族裔差异反映社会决定因素；相关≠因果提示）

技术路线（已确认）：手写 SVG/React 图表（零新依赖，复用 tokens.css 纸色主题）；数据 = raw/ PDF 提取 + 权威公开数据一次性下载内置。

**重要说明**：MentalChat16K（对话语料）与 multilingual-mental-health-datasets-nlp（社交媒体文本分类数据集）经核实均为 NLP 文本数据集，**不含任何流行病学数值**，不用于本栏目（可作为未来对话语料类栏目的素材）。真正的流行病学数据来自：IHME GBD/OWID（按国家×年份×疾病患病率 1990–2021）、SAMHSA NSDUH（美国族裔患病率+治疗率 2008–2023）、世界银行（GDP）、WHO Mental Health Atlas / Eurostat / OECD（精神科医生、床位、支出）。

## 一、数据层

### 1. 新增数据模块 `src/atlas/`（纯数据，提交进 git）
- `spectrum.js` — 谱系定义（id、中文名、色系、概念简述）+ 疾病定义（id、名称、所属谱系、数据可得性标注）
- `coreData.js` — 欧美核心数据（随主包加载）：约 35 个欧美国家 + 美国 50 州 + DC + 美国族裔组的长表记录，紧凑三元组格式 `[geoId, year, diseaseKey, value]` 控制体积（预估压缩后 <300KB）
- `globalData.js` — 全球各国数据（**懒加载分包**，切到"全球范围"时动态 import，不影响现有页面首屏）
- `sources.js` — 数据源注册表（来源、机构、年份范围、许可证、局限性说明）+ 免责声明文案
- `index.js` — 汇总导出 + 轻量查询函数

### 2. 一次性数据管道 `scripts/atlas/`（脚本提交，原始下载缓存放 raw/ 不会被发布）
- `download-public.mjs` — 下载 OWID/GBD 按国家患病率 CSV（抑郁、焦虑、双相、精神分裂症、物质使用、进食障碍，视可得性加 ADHD/自闭谱系）、世界银行 GDP API、WHO Atlas 精神科医生/支出快照、SAMHSA NSDUH 族裔表
- `extract-who-2017.mjs` / `extract-mha.mjs` / `extract-eurostat.mjs` — 用 pdftotext/python 提取 raw/ 中 WHO 2017 附录各国患病率表、MHA 2023–2025 美国州排名表（患病率+未满足治疗需求+无保险率）、Eurostat 精神科医生 2013–2023
- `build-atlas-data.mjs` — 国家名→ISO3 归一、单位换算、去重、数值抽查范围校验 → 生成 `src/atlas/*.js`
- 提取的关键数值人工抽查比对原 PDF

### 3. 数据维度说明（页面文案如实标注）
- **地区视图**：欧美国家按大区分组（西欧/北欧/南欧/东欧/北美/拉美），年份跨度按来源 1990–2023
- **族裔视图**：数据来自美国全国调查（NSDUH 2008–2023，7 个族裔组 × 患病率 × 接受治疗比例）；欧洲无系统性族裔患病率，文案明示
- **可及性柱**：美国州/族裔最完整；欧洲/全球用 WHO Atlas 治疗覆盖率与 OECD 指标快照，缺口年份留空并标注
- **散点维度**：认知度/社会文化用"心理健康支出占卫生预算比""未满足照护需求比例"等代理指标并明确标注为代理

## 二、组件层 `src/components/visualization/`

| 组件 | 职责 |
|---|---|
| `DataAtlasPage.jsx` | 页面骨架（沿用 FrontierReviewsPage 的 focusOnMount/onPageFocused 协议）、免责声明带、数据来源页脚 |
| `PrevalenceMatrix.jsx` | 主矩阵：地区↔族裔切换、年份列、时间滑块+播放、单元格（疾病色相×患病率深浅 + 可及性细柱）、多疾病层叠薄条带模式、无数据格斜纹、悬停提示 |
| `CorrelationScatter.jsx` | 副窗口散点：X/Y 维度选择器、点=国家/族裔（颜色=大区）、Pearson r + 线性拟合、与矩阵悬停双向联动、年份联动 |
| `SpectrumDiseasePicker.jsx` | 谱系分组选择器：谱系色系 chips → 疾病 chips，支持多选层叠 |
| `SpectrumLegend.jsx` | 谱系-疾病-颜色图例与概念说明 |
| `useAtlasData.js` | 状态与查询 hooks、色阶映射、Pearson r 计算 |

交互细节：时间滑块移动"当前年份光标"扫过年份列，驱动散点窗口与柱高亮联动；播放键自动推进；主矩阵悬停某国 → 散点对应点高亮，反向亦然；移动端矩阵横向滚动+首列吸附，散点堆叠在下方。

## 风险与边界（如实告知）

- raw/ 数据全部锁在 PDF 里，需逐表提取并人工抽查；提取脚本一次性运行，产物（src/atlas/*）入库
- 欧洲国家的"治疗可及性"时间序列稀疏（WHO Atlas 只有 2014/2017/2020 等快照），缺口年份将留空标注而非插值造假
- 族裔维度实际是"美国族裔"，页面会明示数据来源与局限
- 散点图的"社会文化/认知度"维度用代理指标（支出占比、未满足需求率），不冒充直接测量
