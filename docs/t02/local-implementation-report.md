## 边界与剩余问题

1. 数据远端只读访问返回 Repository not found；尚不能确认私有仓权限或当前远端状态。没有新增正式数据仓历史，没有改写另一台电脑的提交。后续取得 clone 或 bundle 后，按文件差异接入本机增量。
2. 原 T02 的 `content-pack.lock` 继续 adoption=legacy，publisherIdentity=not_configured，候选 sim-4 不进入生产。`legacy-content.lock` 只是现有本机内容的迁移完整性锁，不是人工批准、身份认证或正式发布通道。
3. 35项机构工具与相关输出仍需权属、参数、输入授权及可重现性复核，特别是旧地图素材和嵌入裁定脚本。历史资产并不因最新目录移出而从 Git 历史消失。
4. 原料许可、358篇事实与医学复核、真实合法输入双跑及可信撤稿渠道需分别验收，不在工程校验中伪造签收。
5. 构建仍有较大的内容和地图 chunk（主包约7.18MB、地图约1.75MB）；未调高警告阈值或扩展到UI/拆包重写。后续可另做按需内容加载。
6. 普通写入异常可恢复旧文件与锁；断电或强制终止期间的多文件导入不保证原子切换，完整性检查会拒绝混合版本。正式自动发布前应采用整目录原子切换等完整发布机制。

本地分仓可继续使用；正式数据仓整合、内容发布及生产采用仍为 PARTIAL/BLOCKED。后续不得据本报告直接 push 或部署。
