# 社交平台与台湾资料研究接入方案

状态：**LOCAL RESEARCH ONLY / NOT APPROVED FOR PUBLICATION**

基线日期：2026-09-01

适用范围：小红书、抖音、知乎样本，以及项目方提供的台湾论文、政策和统计资料

## 1. 决策摘要

1. 原始 JSONL、清洗后的逐条文本、PDF、OCR/抽取文本和项目计划原件都不得提交
   到 Git，也不得进入 `src/`、`public/`、API 或生产构建。
2. 可提交到 topic branch 的只有：确定性清洗程序、合成测试、无个人文本的审计
   结论、数据模型和产品方案。
3. 社交平台样本当前不能生成医院“口碑分”、医疗质量分或排名。现有生产评分
   发布路径暂停，地图继续显示“待数据接入”。
4. “涉及政治正确的敏感言论”不作为自动删帖标准。流程按隐私与安全风险、辱骂
   或去人化表达、公共事务/身份敏感、广告、医学主张和低信息量分别标记；观点
   本身不因立场被删除。公共事务/身份敏感记录进入人工审阅，并从医院体验自动
   汇总中排除。
5. 台湾资料可用于历史趋势、服务可及性和政策入口，不可直接用于大陆医院排名，
   也不可把不同时点、不同定义的数据做横向优劣比较。

## 4. 清洗与审阅流程

1. **冻结来源快照**：记录平台、批次、文件哈希、采集范围和时间，不复制账户、
   cookie、token 或真实本机路径到仓库。
2. **严格解析**：UTF-8 或 JSON 失败即隔离；不得静默丢弃，也不得拼接猜测。
3. **稳定去重**：平台 + 记录类型 + 来源 ID 哈希成内部 ID；同 ID 保留时间较新的
   版本；跨平台仅对足够长的完全相同文本做重复标记。
4. **最小化与遮盖**：不读取作者昵称、主页和账号字段；正文中的手机号、邮箱、
   身份证号、联系方式、网址和 @账号进行遮盖。遮盖后的文本仍视为敏感数据。
5. **安全分流**：高风险个人披露不进入医院体验聚合；它只用于评估分类器召回，
   不作为危机干预渠道，也不联系原作者。
6. **实体解析**：只有作者正文直接提到的规范机构名或经审阅别名才能直接匹配；
   搜索关键词不能证明记录属于该医院。上文继承匹配只作为人工候选。
7. **经历分类**：区分第一人称就诊/陪诊经历与转述、新闻、科普、广告、吐槽、
   医学建议。关注挂号与等待、费用、沟通、流程与隐私、环境、连续照护等非疗效
   维度。
8. **双人审阅**：发布候选需两名审阅者独立判断机构、是否真实服务经历、风险
   标签和维度；分歧由第三人裁决。抽样记录一致率和错误类型。
9. **只发布不可逆汇总**：即便通过审阅，也默认不展示原句、链接、用户名或时间
   细粒度轨迹；小样本不显示，机构应有纠错和撤回渠道。

## 5. 敏感内容规则

| 类别 | 自动动作 | 人工动作 | 可否进入体验汇总 |
| --- | --- | --- | --- |
| 直接个人标识符 | 遮盖并标记 | 检查残留 | 否，直至复核 |
| 自杀、自伤、伤人等个人披露 | 隔离并标记 | 仅做安全分类研究 | 否 |
| 辱骂、污名、去人化表达 | 标记 | 判断引用语境与伤害 | 默认否 |
| 公共事务、政治或身份敏感 | 标记 | 判断是否与服务经历必要相关 | 不自动纳入 |
| 医学诊断、用药、疗效主张 | 标记 | 交医学内容审阅 | 不用于医院质量评分 |
| 广告、引流、代挂号 | 标记 | 识别商业关系 | 否 |
| 正常负面服务经历 | 保留候选 | 核验机构与维度 | 可进入匿名维度统计 |

这套规则过滤的是隐私、安全、归因和数据质量风险，不是把负面评价或特定立场
删除。正常的批评性就诊经历必须与正面经历使用相同标准。

## 6. 产品利用路线

### P0：数据覆盖与缺口研究（现在可做，本地）

- 统计哪些机构有可审阅候选、哪些地区完全没有样本。
- 建立机构别名和误配样本集，测量实体解析准确率。
- 形成“需要官方资料补全”的清单，不向用户显示讨论热度。

### P1：服务路径信息（优先于口碑分）

- 使用官方机构资料展示地址、服务类别、预约方式、费用说明、远程服务和转诊入口。
- 社交样本只帮助发现需要核实的问题，例如“预约步骤是否难找”或“是否需要提前
  确认额外费用”；最终事实必须回到机构或主管部门公开来源。
- 详情页可以展示“信息已核验日期”和“来源”，不展示医院好坏排名。

### P2：经同意的结构化用户贡献

- 若要实现类似角色互动的持续数据采集，应采用明确同意、可跳过、可撤回的结构化
  反馈，而不是把对话默认当训练材料。
- 问题只覆盖非诊断维度：是否找到入口、等待区间、费用是否事前说明、沟通是否
  被尊重、隐私是否得到保护、后续安排是否清楚。
- 不采集病历、真实姓名、身份证、联系方式、精确就诊时间、处方或可重识别叙述。
- 对话角色可以改善填写体验，但不能扮演医生、不能诱导披露危机或医疗隐私，
  也不能未经单独同意用于训练模型。

### P3：公开体验统计（条件满足后才评审）

- 只发布经人工复核的维度分布和样本量，不发布粗粒度情感词“口碑分”。
- 候选门槛建议先作为实验参数验证：足够的独立经历、跨时间覆盖、来源分布、实体
  准确率和审阅一致率；门槛确定前不得写入产品规则。
- 医疗资源、专业资质和用户服务体验应分开展示，不合成单一“医院质量总分”。

## 7. 台湾资料利用方案

### 7.1 历史照护趋势面板

《Ten-year trends in depression care in Taiwan》基于 2007–2016 年全民健保申报
资料，可支持“接受治疗的抑郁症盛行、服务场所、照护过程指标和急诊/住院结局”的
历史趋势说明。它不能评价单家机构，也不能证明资源变化导致结局改善；自费心理
治疗未完整进入申报资料，论文指标也是代理指标。

### 7.2 政策与求助入口卡

附件中的 112–113 年度 15–30 岁方案只作历史版本。现行信息必须从台湾卫生福利部
页面实时核验。115 年度（2026）官方 FAQ 显示，15–45 岁方案实施期为 2026-01-01
至 2026-12-31，每人补助 3 次个别心理咨询，合作机构由官方方案网站查询：

- [台湾卫生福利部：青壮世代心理健康支持方案](https://dep.mohw.gov.tw/domhaoh/fp-7168-80425-107.html)
- [115 年度官方常见问答](https://www.mohw.gov.tw/dl-99089-f57fdce4-63ff-42e5-84f7-e1e121378d61.html)

产品应只保存官方入口、适用年龄、有效期、服务次数、额外费用提醒和最后核验时间；
不得导入申请表、身份证明、筛查量表答案或任何参与者记录。到期后自动标为“待
复核”，不能继续显示为现行权益。

### 7.3 历史资源基线

《世界心理健康日卫生福利统计通报》可形成带明确日期的台湾资源快照，例如 2020
年底心理治疗/咨询机构与专业人员数量，以及 2021 年中精神医疗、复健和护理机构
数据。只能按原始定义展示，不能与大陆机构数直接相除或排名。

### 7.4 可复用的跨地区数据模型

建议增加独立而非混合的字段：`jurisdiction`、`metricDefinition`、`referenceDate`、
`coverage`、`sourceType`、`sourceUrl`、`lastVerifiedAt`、`validFrom`、`validTo`、
`limitations`。地图可在大陆与台湾视图分别使用各自权威来源和术语；跨地区只比较
有相同定义、相近年份和明确分母的指标。

## 8. 评分模型结论

项目计划提出的 40% 大众口碑 + 30% 资源设备 + 30% 专业度，可以保留为早期需求
假设，但不应成为当前生产算法。原因是三类证据的测量尺度、时效、可得性和偏差
不同，社交样本尤其不能代表总体。

下一版应先拆成三个并列证据面板：

1. **官方事实完整度**：执业、服务类别、联系方式、有效期和更新时间；
2. **服务可及性**：预约、等待、费用透明、远程服务、转诊与无障碍；
3. **用户体验研究信号**：只显示经审阅的维度分布、样本量和不确定性。

只有完成数据授权、评分有效性研究、公平性评估、机构纠错机制和产品/医学/法律
审阅后，才能讨论是否需要综合分。即使届时计算，也不得把它命名为医疗质量分。

## 10. 发布门禁

在以下事项全部完成前，结论保持 **NOT APPROVED FOR PUBLICATION**：

- 平台来源授权、使用条款和保留期限有书面记录；
- 直接与间接重识别风险完成隐私评估；
- 机构实体解析在独立标注集上测得准确率，并审阅通用名称误配；
- 人工审阅规范、双人一致率和申诉/撤回流程已建立；
- 最小样本、时间窗、机器人/广告排除和平台偏差规则经验证；
- 任何用户文案经过产品、医学内容、隐私/法律和无障碍审阅；
- 生产测试证明原始文本、原帖链接、账号信息和本地研究文件不会进入构建产物。
