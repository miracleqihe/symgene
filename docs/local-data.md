# 本地数据说明

本地编辑和数据管理能力只在开发模式开放。公开生产版本是只读界面。

## 主数据与版本

主键为：

```text
symgene-wiki-data-v1
```

键名为兼容旧安装保持不变，值已经升级为存储信封：

```json
{
  "schemaVersion": 2,
  "seedVersion": 11,
  "savedAt": "2026-07-29T12:00:00.000Z",
  "data": {
    "drugs": [],
    "disorders": [],
    "cases": [],
    "resources": []
  },
  "deletedIds": {
    "drugs": [],
    "disorders": [],
    "cases": [],
    "resources": []
  }
}
```

`schemaVersion` 表示存储结构，`seedVersion` 表示项目内置内容版本。两者不能混用。`deletedIds` 记录用户明确删除的内置条目，防止后续种子合并将其恢复。

## 迁移与合并顺序

读取旧 `meta.version` 格式或较早信封时，流程为：

1. 读取并保留原始字符串；
2. 在项目自己的备份键下创建逐字备份；
3. 解析旧格式并建立当前信封；
4. 按“用户修改优先、用户删除优先、新种子补充”的规则合并；
5. 运行与正式数据相同的完整性验证；
6. 仅在验证通过后写回主键。

用户新增条目和同 ID 修改会保留；新种子只补充不存在且未被删除的 ID。自定义条目删除后不必保留 tombstone，内置条目删除则会记录。迁移失败会保留原始主值、显示非敏感错误，并阻止普通编辑覆盖故障数据。

旧 `meta.version: 10` 到当前版本的内容基线相同。未来若在兼容旧格式的同时更换种子内容，应保留相应旧种子 ID 清单，才能准确区分历史删除与新种子新增。

## 自动备份

自动备份键以 `symgene-wiki-backup-` 开头，最多保留最近 5 份。清理仅匹配该前缀，不删除主数据或其他应用的本地存储。

以下操作会先备份当前值：

- 自动迁移写回；
- 导入备份；
- 恢复自动备份；
- 恢复项目默认数据。

数据面板可以查看备份时间、结构版本、种子版本和大小，也可以导出原始备份。无效备份不能恢复。

## 导出与导入

导出文件名形如 `symgene-backup-2026-07-29.json`，MIME 类型为 JSON。文件包含：

- 固定格式标识 `symgene-local-backup`；
- 结构和种子版本；
- 导出时间；
- 四类实际数据；
- 删除记录。

导出不包含搜索描述、浏览器信息、日志或用户身份信息，也不会发送网络请求。

导入文件上限为 5 MB。程序实际读取并解析 JSON，不只检查扩展名。导入会验证格式标识、版本、重复 ID、必填字段、交叉引用、资源 URL 和本地路径；未来版本与无效文件会被拒绝。确认界面只显示数量、增加/覆盖数量、删除记录数量和版本，不显示全部内容。

导入文本只作为数据处理和普通 React 文本展示，不执行 HTML、脚本或模块，也不会自动访问其中的 URL。用户取消确认时不会写入。

## 恢复默认数据

恢复默认数据会先备份当前状态，然后恢复当前种子并清空删除记录。它不会删除其他应用的 `localStorage` 键。该操作会从当前状态移除用户新增和修改内容，因此必须先确认。

清除浏览器站点数据会同时删除主数据和自动备份。如需保留本地编辑内容，请先导出备份。

## 隐私边界

浏览器本地存储不是安全加密存储。请勿录入真实患者姓名、联系方式、地址、病历号或任何可以识别个人身份的信息。仓库、测试夹具和问题报告同样不得包含真实患者资料、原始书籍内容、OCR 文本或私人文件路径。
